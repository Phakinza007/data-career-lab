## โปรแกรมต้องการข้อมูลเชิงโครงสร้าง แต่โมเดลตอบเป็นข้อความ

เมื่อต้องส่งผลของ LLM ไปเก็บลงฐานข้อมูลหรือให้โค้ดอื่นใช้ เราขอให้ตอบเป็น JSON — และต้องเตรียมรับความจริงว่า **บางครั้งมันไม่ใช่ JSON ที่ถูกต้อง** เช่น มีคำเกริ่นนำ ห่อด้วย ```json, ใช้เครื่องหมาย ' แทน ", ขาดฟิลด์ หรือค่าผิดชนิด

> ตัวอย่างในบทนี้ใช้ผลลัพธ์ที่ **จำลอง** ไว้ 8 แบบ (list `RAW`) เพื่อให้ทดสอบซ้ำได้ ไม่ได้เรียกโมเดลจริง — ของจริงลดปัญหาได้ด้วยการใช้ความสามารถ structured output / tool use ที่ให้ระบุ JSON schema (ตามเอกสารของผู้ให้บริการ) แต่ก็ยัง **ต้องตรวจฝั่งเราเสมอ**

## ขั้น 1: parse แบบเข้มงวดก่อน

```python
import json
try:
    obj = json.loads(text)
except json.JSONDecodeError:
    obj = None
```

จาก 8 ตัวอย่าง parse ตรงๆ ได้ 5 ตัว (ตัวที่พังคือ: มีข้อความนำหน้า, ใช้ single quote, ไม่มี JSON เลย)

## ขั้น 2: ดึง JSON ออกจากข้อความที่ปนกัน

```python
import re
match = re.search(r"\{.*\}", text, re.S)     # re.S ให้ . ข้ามบรรทัดใหม่ได้
obj = json.loads(match.group(0)) if match else None
```

วิธีแบบ lenient (ลอง strict ก่อน ไม่ได้ค่อยดึงด้วย regex) ทำให้ได้ 6 จาก 8 — ตัวที่ใช้ single quote ยังพัง (เพราะไม่ใช่ JSON) และตัวที่ตอบเป็นประโยคไม่มี JSON ให้ดึง
regex แบบ `{.*}` เป็นแบบง่าย: ใช้ได้เมื่อมีวัตถุ JSON ก้อนเดียว ถ้ามีหลายก้อนต้องเขียนให้รัดกุมกว่านี้

## ขั้น 3: ตรวจ schema (parse ได้ ≠ ใช้ได้)

ตรวจทุกครั้งว่า: มีฟิลด์ที่ต้องมีครบ, ค่าอยู่ในชุดที่อนุญาต (enum), ชนิดถูก, ช่วงค่าถูก

| ผลลัพธ์ | ปัญหา |
|---|---|
| `"confidence": "0.7"` | ชนิดผิด (string) — แก้ด้วยการ coerce เป็น float ได้ |
| `"category": "billing"` | ไม่อยู่ในป้ายกำกับที่อนุญาต |
| ไม่มี `confidence` | ขาดฟิลด์ |
| `"confidence": 1.4` | นอกช่วง 0–1 |

การ coerce (แปลงชนิดให้) ควรทำเฉพาะกรณีที่ชัดเจนและปลอดภัย (สตริงตัวเลข → float) ส่วนค่าที่ผิดความหมาย (หมวดไม่มีจริง, ค่านอกช่วง) ต้องปฏิเสธหรือขอให้โมเดลแก้ (บทถัดไป)
ผลของ 8 ตัวอย่าง: ผ่านตรวจแบบไม่ coerce 2 ตัว, แบบ coerce 3 ตัว

หลักการ: **ถือว่าผลลัพธ์ของโมเดลเป็นข้อมูลที่ไม่น่าไว้ใจ** เหมือนอินพุตจากผู้ใช้ — ตรวจก่อนใช้เสมอ (ไลบรารีอย่าง pydantic / jsonschema ทำหน้าที่นี้ในงานจริง; ที่นี่เขียนเองเพื่อเข้าใจหลักการ)
