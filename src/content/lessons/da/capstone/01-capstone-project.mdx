## โจทย์ของ capstone

เลือกคำถามธุรกิจ 1 ข้อจาก dataset นี้ (ร้านค้าออนไลน์: `customers`, `orders`, `order_items`, `products`, `events`)
แล้วตอบให้ครบวงจร — ตั้งคำถาม → เตรียม/สำรวจข้อมูล → วิเคราะห์ → สรุปเป็น insight ที่มีตัวเลขและ "แล้วไง" ชัดเจน
(เชื่อมกับสิ่งที่เรียนในบท เขียน insight จากกราฟ)

ตัวอย่างโจทย์ที่เลือกได้ (หรือคิดเองก็ได้):

- ลูกค้ากลุ่มไหนควรได้รับความสำคัญมากที่สุด? (ใช้บท RFM segmentation)
- funnel ขั้นไหนควรแก้ก่อน? (ใช้บท วิเคราะห์ funnel)
- แคมเปญ promo เดือน มิ.ย. 2025 คุ้มค่าจริงไหม? (ใช้บท Cohort และ retention)
- หมวดสินค้าไหนควรเพิ่มสต็อก? (ใช้บท correlation/visualization)

## โครงงานที่คาดหวัง

ทำใน Jupyter notebook (ไม่ใช่ในเว็บนี้) — โหลด notebook เริ่มต้นด้วยปุ่มด้านบน มีโครงเซลล์ไว้ให้แล้ว
(โหลดข้อมูล → สำรวจ → วิเคราะห์ → กราฟ → เขียน insight) แต่เนื้อหาในแต่ละส่วนเป็นของผู้เรียนเอง

## Rubric ตรวจงานตัวเอง

ก่อนถือว่างานเสร็จหรือจะเผยแพร่ ให้เช็คทีละข้อ:

- [ ] คำถามชัดเจน ตอบได้จริงด้วยข้อมูลที่มี
- [ ] ใช้ pandas/SQL ถูกต้อง ไม่มี error หรือ logic ผิด
- [ ] มีกราฟอย่างน้อย 1 อันที่เลือกชนิดถูกกับคำถาม พร้อม title/label ครบ
- [ ] มี insight อย่างน้อย 1 ข้อที่มีทั้งตัวเลข เทียบกับ baseline และ "แล้วไง"
- [ ] notebook รันได้ทั้งไฟล์จากบนลงล่างโดยไม่ error
- [ ] ถ้าจะเผยแพร่ ต้องมี README สั้นๆ อธิบายว่าโปรเจกต์นี้ตอบคำถามอะไร

## วิธีเผยแพร่บน GitHub

1. สร้าง public repo ใหม่ (หรือใช้ repo เดิม)
2. เพิ่มไฟล์ notebook และไฟล์ข้อมูลที่ใช้ (หรือลิงก์ไปที่ dataset นี้)
3. เขียน `README.md` สั้นๆ (โจทย์ + วิธีรัน + สรุปผล 2-3 บรรทัด)
4. commit + push
5. แปะลิงก์ repo ใน resume/LinkedIn ได้เลย
