## cohort คืออะไร

**Cohort** คือกลุ่มลูกค้าที่เข้าร่วม (ในที่นี้คือสมัครสมาชิก) ในช่วงเวลาเดียวกัน — ใช้เปรียบเทียบพฤติกรรมของกลุ่ม
ต่างๆ ข้ามช่วงเวลาได้ เช่น "คนที่สมัครเดือน มิ.ย. กลับมาซื้อซ้ำมากน้อยแค่ไหนเทียบกับคนที่สมัครเดือน ก.ค."

```python
c = customers.assign(cohort=lambda d: d.signup_date.str[:7])
```

## retention คืออะไร

ในบทนี้นิยาม **retention** ว่าคือสัดส่วนลูกค้าที่สั่งซื้อตั้งแต่ 2 ครั้งขึ้นไป **นับทุกสถานะออเดอร์** (ต่างจากบทที่แล้ว
ที่นับเฉพาะออเดอร์ `completed` เพราะคำถามคือ "ลูกค้ากลับมาลองซื้ออีกไหม" ไม่ใช่ "ลูกค้าซื้อสำเร็จซ้ำไหม"):

```python
k = orders.groupby('customer_id').size().rename('n_orders')
merged = customers.merge(k, on='customer_id', how='left').fillna({'n_orders': 0})
retention = (merged['n_orders'] >= 2).mean()
```

## เจอ retention ต่ำผิดปกติ — อย่ารีบสรุป

ถ้า cohort เดือนหนึ่งมี retention ต่ำกว่าเดือนข้างเคียงมาก ขั้นแรกที่ควรทำคือ **ตรวจดูองค์ประกอบของ cohort นั้น**
ก่อนสรุปว่าเป็นปัญหาของช่วงเวลานั้นเอง เช่น เช็คว่าคนกลุ่มนั้นมาจากช่องทางไหนบ้าง:

```python
june = c[c['cohort'] == '2025-06']
june['channel'].value_counts()
```

บ่อยครั้งที่ retention ต่ำผิดปกติของ cohort หนึ่ง แท้จริงแล้วเป็นปัญหาของ**ช่องทางที่พาลูกค้าเข้ามา** ไม่ใช่ปัญหาของ
ช่วงเวลานั้นเอง — cohort นั้นแค่บังเอิญมีคนจากช่องทางที่มีปัญหาเข้ามาเยอะเป็นพิเศษ
