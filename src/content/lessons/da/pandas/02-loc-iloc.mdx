## label กับ position

pandas มีสองวิธีหลักในการเลือกแถว/คอลัมน์:

| | อ้างอิงด้วย | ตัวอย่าง |
| --- | --- | --- |
| `.loc` | label (ชื่อคอลัมน์ / ค่าดัชนี) | `df.loc[3]` → แถวที่มี index label เป็น `3` |
| `.iloc` | position (ตำแหน่ง เริ่มจาก 0) | `df.iloc[3]` → แถวที่ 4 นับจากบน ไม่ว่า label จะเป็นอะไร |

ถ้า DataFrame มี index เป็นตัวเลขเรียงต่อกันตั้งแต่ 0 (ค่าเริ่มต้นหลัง `read_csv`) `.loc[3]` กับ `.iloc[3]`
จะให้ผลเหมือนกัน แต่ถ้า index ถูกเปลี่ยน (เช่นด้วย `.set_index()` หรือหลังกรอง/เรียงข้อมูล) สองอันนี้จะให้ผลต่างกันทันที

## เลือกทั้งแถวและคอลัมน์พร้อมกัน

```python
products.loc[products['category'] == 'Books', ['product_name', 'price']]
products.iloc[0:3, 0:2]
```

ใส่แกนแถวและแกนคอลัมน์ในวงเล็บเดียวกัน คั่นด้วยจุลภาค — ทำได้ในคำสั่งเดียว ไม่ต้องเขียนกรองแล้วเลือกคอลัมน์แยกกัน

## ช่วง (slice): .loc รวมขอบท้าย, .iloc ไม่รวม

```python
df.loc[0:2]    # ได้ label 0, 1, 2 (3 แถว — รวมขอบท้าย)
df.iloc[0:2]   # ได้ตำแหน่ง 0, 1 (2 แถว — ไม่รวมขอบท้าย เหมือน slice ปกติของ Python)
```

นี่คือจุดที่มือใหม่มักสับสน: `.loc` ปฏิบัติต่อช่วงแบบ "รวมทั้งสองขอบ" ในขณะที่ `.iloc` (และ slice ของ Python
ทั่วไปอย่าง `list[0:2]`) ปฏิบัติแบบ "ไม่รวมขอบท้าย" จำไว้ว่า `.loc` เป็นข้อยกเว้น ไม่ใช่กติกาปกติ

## ตั้ง index เอง แล้วใช้ .loc อ้างอิงด้วย label ที่มีความหมาย

```python
orders.set_index('order_id').loc[1]   # ดึงออเดอร์ที่ order_id = 1 โดยตรง
```

การตั้งคอลัมน์ที่มีความหมาย (เช่น รหัสที่ไม่ซ้ำ) เป็น index แล้วใช้ `.loc` อ้างอิงด้วยรหัสนั้นตรงๆ
อ่านง่ายกว่าการกรองด้วยเงื่อนไข `df[df['order_id'] == 1]` เมื่อรู้ค่าที่ต้องการแน่นอนอยู่แล้ว
