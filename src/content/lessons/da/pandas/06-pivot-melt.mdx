## สร้างตารางสรุปแบบ "กว้าง" ด้วย pivot_table

```python
orders.pivot_table(values='order_id', index='status', columns='payment_method', aggfunc='count', fill_value=0)
```

| พารามิเตอร์ | ความหมาย |
| --- | --- |
| `values` | คอลัมน์ที่จะเอาไปสรุป |
| `index` | คอลัมน์ที่จะเป็น "แถว" ของตารางผลลัพธ์ |
| `columns` | คอลัมน์ที่จะเป็น "คอลัมน์" ของตารางผลลัพธ์ (ไม่ใส่ก็ได้ ถ้าอยากได้แค่ 1 มิติ) |
| `aggfunc` | ฟังก์ชันสรุป (`'count'`, `'sum'`, `'mean'`, ...) |
| `fill_value` | ค่าที่ใส่แทนช่องที่ไม่มีข้อมูล (ปกติจะเป็นค่าว่าง) |

`pivot_table` เหมาะมากเมื่ออยากดูข้อมูล 2 มิติ (แถว×คอลัมน์) พร้อมกันในตารางเดียว — ต่างจาก `groupby`
ที่ให้ผลเป็นรูปแบบ "ยาว" เสมอ

**ระวัง:** ถ้าใส่ `aggfunc` เป็น list มากกว่า 1 ฟังก์ชัน (เช่น `['min', 'max']`) จะได้คอลัมน์ซ้อนกัน
(MultiIndex) ที่ดึงค่ายากกว่าปกติมาก ถ้าต้องการหลายฟังก์ชันพร้อมกัน ใช้ `.agg()` แบบตั้งชื่อเอง (บทที่ 4) แทน

## แปลงกว้างเป็นยาวด้วย melt

```python
products[['product_id', 'price', 'cost']].melt(id_vars='product_id')
```

`melt` คือการย้อนกลับของ `pivot_table` — เอาหลายคอลัมน์ (`price`, `cost`) มาแปลงเป็นแถว
โดยมี `id_vars` เป็นคอลัมน์ที่ยังคงอยู่เดิม (บอกว่าแต่ละแถวเป็นของอะไร) ผลลัพธ์จะมีคอลัมน์ `variable`
(ชื่อคอลัมน์เดิม) กับ `value` (ค่าเดิม) — ตั้งชื่อเองได้ด้วย `var_name=`/`value_name=`

**ระวัง:** ถ้าลืมใส่ `id_vars` จะเอาทุกคอลัมน์ไปแปลงเป็นแถวหมด ไม่เหลือคอลัมน์บอกที่มาของแต่ละแถวเลย
