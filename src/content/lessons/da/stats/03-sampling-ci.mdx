## ทำไมต้องสุ่มตัวอย่างแทนการดูข้อมูลทั้งหมด

ในความเป็นจริง เรามักไม่มีข้อมูล**ทั้งประชากร** (population) ให้ดูตรงๆ — บางทีข้อมูลทั้งหมดมีมากเกินกว่าจะประมวลผลได้เร็ว
บางทีก็เก็บมาไม่ครบทุกหน่วยจริงๆ (เช่น สำรวจความเห็นลูกค้าทุกคนบนโลกเป็นไปไม่ได้) เราจึงต้อง**สุ่มตัวอย่าง** (sample)
มาส่วนหนึ่ง แล้วใช้สถิติจากตัวอย่างนั้นมา**ประมาณ**ค่าจริงของประชากร

คำถามสำคัญคือ: ถ้าเราสุ่มตัวอย่างมาแค่ส่วนหนึ่ง ค่าเฉลี่ยที่คำนวณได้จากตัวอย่างจะ "ใกล้เคียง" ค่าเฉลี่ยจริงแค่ไหน
และเราจะบอกความไม่แน่นอนนั้นออกมาเป็นตัวเลขได้ยังไง — นี่คือสิ่งที่ **standard error** และ **confidence interval (CI)** ตอบ

### การสุ่มตัวอย่างแบบทำซ้ำได้ (reproducible)

ทุกตัวอย่างและแบบฝึกในบทนี้ใช้ยอดขายต่อออเดอร์ (completed-order revenue) ชุดเดียวกัน สร้างจาก `order_items`
รวมกับ `orders` เฉพาะออเดอร์ที่ `status == 'completed'` แล้ว group ตาม `order_id`:

```python
import pandas as pd
import numpy as np

orders = pd.read_csv("data/orders.csv")
order_items = pd.read_csv("data/order_items.csv")

merged = order_items.merge(orders, on='order_id')
completed = merged[merged['status'] == 'completed'].copy()
completed['line'] = completed['quantity'] * completed['unit_price']
order_rev = completed.groupby('order_id')['line'].sum()
```

`order_rev` คือ Series ของยอดขายต่อออเดอร์ทั้งหมด 6232 ออเดอร์ — นี่คือ "ประชากร" ในบทนี้ (ค่าเฉลี่ยจริง ≈ 5220.15 บาท)

จากนั้นสุ่มตัวอย่างมา 200 ออเดอร์ด้วย `numpy.random.default_rng` — การกำหนด **seed** (ในที่นี้คือ `42`) ทำให้สุ่มได้ผลลัพธ์
**เดิมทุกครั้งที่รันใหม่** ซึ่งสำคัญมากสำหรับการเรียน (ทุกคนได้ตัวเลขตรงกัน ตรวจคำตอบได้แน่นอน):

```python
rng = np.random.default_rng(42)
sample = rng.choice(order_rev.values, size=200, replace=False)
```

**สำคัญ:** ทุกแบบฝึกในบทนี้ต้องสร้าง `sample` ด้วยวิธีนี้เป๊ะๆ (seed `42`, `size=200`, `replace=False`)
ถ้าเปลี่ยน seed หรือขนาดตัวอย่าง จะได้ตัวเลขคนละชุด

## Standard error — ความไม่แน่นอนของค่าเฉลี่ยตัวอย่าง

ค่าเฉลี่ยของตัวอย่าง (`sample.mean()`) ไม่มีทางเท่ากับค่าเฉลี่ยจริงของประชากรเป๊ะๆ เสมอไป — มันแกว่งไปมาได้ตามตัวอย่างที่สุ่มมา
**standard error (SE)** คือค่าที่บอกว่าค่าเฉลี่ยตัวอย่างแกว่งได้มากแค่ไหนโดยเฉลี่ย คำนวณจาก:

```
SE = ส่วนเบี่ยงเบนมาตรฐานของตัวอย่าง (sample std) / รากที่สองของขนาดตัวอย่าง (sqrt(n))
```

```python
sample_mean = sample.mean()            # ≈ 6233.38
sample_std = sample.std(ddof=1)        # ≈ 9141.73
se = sample_std / np.sqrt(200)         # ≈ 646.42
```

สังเกตว่า `sample_mean` (≈ 6233.38) สูงกว่าค่าเฉลี่ยจริงของประชากร (≈ 5220.15) พอสมควร — นี่คือ**โชคของตัวอย่างนี้เพียงชุดเดียว**
ล้วนๆ (ยอดขายเบ้ขวามาก มีออเดอร์ก้อนใหญ่หลุดเข้ามาในตัวอย่างพอดี) นี่คือเหตุผลว่าทำไมเราไม่ควรรายงานค่าเฉลี่ยตัวอย่างเป็น
"จุดเดียว" เฉยๆ โดยไม่บอกช่วงความไม่แน่นอนกำกับไว้ด้วย

ยิ่งขนาดตัวอย่าง (`n`) ใหญ่ขึ้น SE จะยิ่งเล็กลง (หารด้วย `sqrt(n)` ที่ใหญ่ขึ้น) — ตัวอย่างใหญ่ขึ้นทำให้ค่าเฉลี่ยตัวอย่างนิ่งขึ้น
ใกล้เคียงค่าจริงมากขึ้นโดยเฉลี่ย

## Confidence interval (ช่วงความเชื่อมั่น) ด้วย t-distribution

แทนที่จะรายงานแค่ `sample_mean` ค่าเดียว เรารายงานเป็น**ช่วง** ที่คาดว่าครอบคลุมค่าเฉลี่ยจริง — เรียกว่า **confidence interval (CI)**

สูตรทั่วไป:

```
CI = sample_mean ± (ค่าวิกฤต) × SE
```

เมื่อเราไม่รู้ส่วนเบี่ยงเบนมาตรฐานของประชากรจริง (ต้องประมาณจากตัวอย่างเอง) ค่าวิกฤตที่ถูกต้องมาจาก
**t-distribution** (ไม่ใช่ normal distribution ตรงๆ) โดยใช้ degrees of freedom `df = n - 1`:

```python
from scipy import stats

tcrit = stats.t.ppf(0.975, df=199)     # ≈ 1.972 (95% CI ใช้ 0.975 เพราะเผื่อสองด้าน)

ci_low = sample_mean - tcrit * se      # ≈ 4958.67
ci_high = sample_mean + tcrit * se     # ≈ 7508.08
```

ในตัวอย่างนี้ ค่าเฉลี่ยประชากรจริง (≈ 5220.15) **อยู่ภายใน** ช่วง `[4958.67, 7508.08]` พอดี — เป็นภาพสะท้อนที่ซื่อสัตย์ของข้อมูลจริง
(ไม่ได้จัดฉากให้ตรงเป๊ะเสมอไป)

> **ข้อควรระวัง:** บางคนใช้ค่าวิกฤตจาก normal distribution (`1.96`) แทน t-distribution เพราะจำได้ขึ้นใจ — กับ `df=199`
> (ตัวอย่างใหญ่) ตัวเลขทั้งสองใกล้กันมาก (`1.972` vs `1.96`) เลยดูเหมือนไม่มีปัญหา แต่ถ้าตัวอย่างมีขนาดเล็ก (เช่น `n=10`)
> ค่าวิกฤตจาก t-distribution กับ normal distribution จะต่างกันมาก — ใช้ `1.96` ผิดๆ ตอนตัวอย่างเล็กจะทำให้ CI แคบเกินจริง
> (มั่นใจเกินความเป็นจริง)

## ตีความ CI ให้ถูก

การตีความที่ผิดที่พบบ่อยที่สุดคือ: *"มีโอกาส 95% ที่ค่าเฉลี่ยจริงอยู่ในช่วงนี้"* — ประโยคนี้ฟังดูเป็นธรรมชาติแต่ผิดหลักการ
เพราะค่าเฉลี่ยจริงของประชากร**ไม่ใช่ตัวแปรสุ่ม** มันเป็นค่าคงที่ค่าหนึ่ง (แค่เราไม่รู้) ส่วนช่วง `[ci_low, ci_high]`
ต่างหากที่เป็นตัวแปรสุ่ม (เปลี่ยนไปตามตัวอย่างที่สุ่มมาได้)

การตีความที่ถูกต้อง: **"ถ้าเราสุ่มตัวอย่างขนาดเท่านี้ซ้ำแบบนี้ 100 ครั้ง แล้วคำนวณ CI ทุกครั้ง จะมีประมาณ 95 ครั้ง
ที่ช่วงที่ได้ครอบคลุมค่าเฉลี่ยจริง"** — ความเชื่อมั่น 95% อยู่ที่**กระบวนการสุ่มตัวอย่างและคำนวณ** ไม่ใช่การ์ดเดิมพันของช่วงใดช่วงหนึ่งเจาะจง

## สรุปภาพรวม

| ค่า | สูตร | ในตัวอย่างนี้ |
| --- | --- | --- |
| standard error | `sample_std / sqrt(n)` | ≈ 646.42 |
| t-critical (95%, df=199) | `stats.t.ppf(0.975, df)` | ≈ 1.972 |
| 95% CI | `sample_mean ± tcrit × se` | `[4958.67, 7508.08]` |
