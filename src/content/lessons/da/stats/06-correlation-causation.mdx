## จาก A/B test สู่ correlation

บทที่แล้วเรียนเรื่อง A/B testing ไปแล้ว — จุดแข็งของ A/B test คือการ**สุ่ม**ผู้ใช้เข้ากลุ่ม ทำให้ถ้าเจอความต่าง
ที่มีนัยสำคัญ เราสรุปได้ค่อนข้างมั่นใจว่า "การเปลี่ยนแปลงที่ทำ" เป็น**เหตุ**ของความต่างนั้นจริง เพราะการสุ่มทำให้
ปัจจัยอื่นๆ ถูกกระจายเท่าๆ กันในทั้งสองกลุ่มโดยเฉลี่ย

แต่ข้อมูลส่วนใหญ่ที่ DA เจอในชีวิตจริงไม่ได้มาจากการทดลองแบบสุ่ม — มันคือข้อมูลที่เกิดขึ้นเองตามธรรมชาติของธุรกิจ
(observational data) บทนี้จะเรียนเครื่องมือที่ใช้บอกว่าตัวแปรสองตัว "สัมพันธ์กัน" แค่ไหน (correlation) และ
ที่สำคัญกว่านั้นคือ**กับดัก**ที่พบบ่อยที่สุดข้อหนึ่งของการวิเคราะห์ข้อมูล: การเห็นว่าสองอย่างสัมพันธ์กันแล้วรีบสรุปว่า
อย่างหนึ่งเป็น**เหตุ**ให้เกิดอีกอย่างหนึ่ง

## Pearson correlation coefficient

**Pearson correlation coefficient** (มักเขียนแทนด้วย `r`) วัดว่าตัวแปรตัวเลขสองตัวมีความสัมพันธ์แบบ**เชิงเส้น**
(linear) กันมากแค่ไหน ค่า `r` อยู่ในช่วง -1 ถึง 1:

| ค่า r | ความหมาย |
| --- | --- |
| ใกล้ +1 | สัมพันธ์เชิงบวกแรง (ตัวหนึ่งขึ้น อีกตัวก็ขึ้นตาม เป็นเส้นตรง) |
| ใกล้ -1 | สัมพันธ์เชิงลบแรง (ตัวหนึ่งขึ้น อีกตัวลง เป็นเส้นตรง) |
| ใกล้ 0 | แทบไม่มีความสัมพันธ์เชิงเส้น |

pandas มีเมธอด `.corr()` ให้ใช้ตรงๆ ระหว่าง Series สองตัว:

```python
import pandas as pd

products = pd.read_csv("data/products.csv")
r = products['price'].corr(products['cost'])
r   # 0.9957
```

`r = 0.9957` ใกล้ 1 มาก แปลว่าราคาขาย (`price`) กับต้นทุน (`cost`) ของสินค้าสัมพันธ์กันแรงมากในเชิงเส้น —
สินค้าต้นทุนสูงมักขายแพง สินค้าต้นทุนต่ำมักขายถูก

## สัมพันธ์กันแรง ≠ อย่างหนึ่งเป็นเหตุของอีกอย่างหนึ่ง

พอเห็น `r = 0.9957` หลายคนจะรีบสรุปว่า "ต้นทุนสูงทำให้ราคาสูง" หรือ "ตั้งราคาสูงทำให้ต้นทุนสูง" — แต่การสรุปแบบนี้
ข้ามขั้นตอนสำคัญไป ความสัมพันธ์ทางสถิติ (correlation) บอกแค่ว่าตัวเลขสองชุด**เคลื่อนไหวไปด้วยกัน** แต่ไม่ได้บอกว่า
ทำไมถึงเคลื่อนไหวไปด้วยกัน อาจเป็นไปได้สามแบบ: A ทำให้เกิด B, B ทำให้เกิด A, หรือมี**ตัวแปรที่สาม**ที่ทำให้ทั้ง A และ B
เกิดขึ้นพร้อมกัน

ตัวแปรที่สามแบบหลังนี้เรียกว่า **confounding variable** (ตัวแปรกวน) — ตัวแปรที่ส่งผลต่อทั้งสองตัวแปรที่กำลังดูอยู่
พร้อมกัน ทำให้สองตัวแปรนั้นดูสัมพันธ์กันทั้งที่ไม่ได้เป็นเหตุเป็นผลกันโดยตรง

ในกรณีของ `price` กับ `cost` ตัวแปรกวนคือ **category** (หมวดหมู่สินค้า) — สินค้าแต่ละหมวด (Electronics, Fashion,
Home ฯลฯ) มีทั้งช่วงราคาและอัตราส่วนต้นทุนต่อราคาเป็นของตัวเอง ลองดูราคาเฉลี่ยแยกตามหมวด:

```python
products.groupby('category')['price'].mean()
# Electronics แพงกว่า Sports, Sports แพงกว่า Home, ...
```

หมวดสินค้าคือสิ่งที่กำหนดทั้งช่วงราคาและช่วงต้นทุนไปพร้อมกันตั้งแต่ต้น ไม่ใช่ว่าต้นทุนไปดันราคาโดยตรงเพียงอย่างเดียว
— แม้ในทางปฏิบัติ ธุรกิจจริงก็มักตั้งราคาจากสูตรที่อิงต้นทุนอยู่บ้าง (เช่น cost-plus pricing) ดังนั้นในเคสนี้จึงน่าจะเป็น
ทั้ง**ตัวแปรกวนร่วม** (category) **และกลไกเชิงตรงบางส่วน** (สูตรตั้งราคาจากต้นทุน) ปนกันอยู่ ไม่ใช่เรื่องเดียวล้วนๆ

## ไม่มี correlation ก็ไม่ได้แปลว่าไม่มีเหตุ-ผล

กับดักอีกด้านหนึ่งคือการสรุปในทิศทางตรงข้าม: เจอ `r` ใกล้ 0 แล้วรีบสรุปว่า "ไม่มีความสัมพันธ์เชิงเหตุ-ผลแน่นอน"
ลองดูตัวอย่าง: ทีมการตลาดเชื่อว่าส่วนลด (`discount_pct`) น่าจะทำให้ลูกค้าซื้อของมากขึ้น (ยอดต่อออเดอร์สูงขึ้น)

```python
r_discount_rev = orders['discount_pct'].fillna(0).corr(order_revenue)
r_discount_rev   # -0.022
```

`r = -0.022` ใกล้ 0 มาก แปลว่าแทบไม่มีความสัมพันธ์เชิงเส้นระหว่างส่วนลดกับยอดต่อออเดอร์ในข้อมูลชุดนี้เลย — ทั้งที่
เรื่องเล่าเชิงธุรกิจ ("ลดราคาแล้วคนซื้อเยอะขึ้น") ฟังดูสมเหตุสมผล

แต่การไม่เจอ correlation ไม่ได้พิสูจน์ว่าผลเชิงเหตุ-ผลไม่มีอยู่จริง เป็นไปได้ว่า:

- ผลกระทบจริงถูกปัจจัยอื่นกลบไว้ (เช่น ลูกค้าที่ได้ส่วนลดกับลูกค้าที่ไม่ได้ อาจเป็นคนละกลุ่มพฤติกรรมกันตั้งแต่ต้น)
- ความสัมพันธ์อาจไม่ใช่แบบเส้นตรง — Pearson correlation จับได้แค่ความสัมพันธ์**เชิงเส้น**เท่านั้น ถ้าส่วนลดมีผลจริง
  แต่เป็นรูปแบบโค้ง (เช่น ได้ผลดีเฉพาะช่วงส่วนลด 5-10% แต่ช่วงอื่นไม่ได้ผล) `r` ที่คำนวณได้อาจใกล้ 0 ทั้งที่มีความสัมพันธ์
  อยู่จริง

## จะรู้ได้ยังไงว่าเป็นเหตุ-ผลจริง

เมื่อเจอตัวแปรสองตัวที่สัมพันธ์กันแรงในข้อมูล observational (ไม่ได้มาจากการทดลองสุ่ม) วิธีตรวจสอบว่าเป็นเหตุ-ผลจริง
หรือแค่ confounded มีหลักคร่าวๆ ดังนี้:

1. **ทำ A/B test แบบสุ่มจริง** ถ้าทำได้ — นี่คือวิธีที่แข็งแรงที่สุดในการพิสูจน์เหตุ-ผล เพราะการสุ่มตัดผลของตัวแปรกวนออกไป
2. **ควบคุมตัวแปรที่สงสัยว่าเป็นตัวกวน** เช่น เทียบ correlation ของ price/cost **ภายในแต่ละ category แยกกัน**
   แทนที่จะดูรวมทุกหมวด ถ้า correlation ยังแรงอยู่แม้ควบคุม category แล้ว ก็เป็นหลักฐานว่ามีกลไกเชิงตรงอยู่จริงด้วย
3. **ใช้ domain knowledge** ประกอบเสมอ — ถามว่า "มีกลไกอะไรที่สมเหตุสมผลที่ A จะทำให้เกิด B" ก่อนสรุปอะไรจากตัวเลขล้วนๆ

ตัวอย่างคลาสสิกที่ใช้สอนเรื่องนี้กันทั่วไป: ยอดขายไอศกรีมกับจำนวนคนจมน้ำในแต่ละเดือนมีความสัมพันธ์กันสูงมาก — แต่ไม่ใช่
เพราะไอศกรีมทำให้คนจมน้ำ ทั้งสองอย่างสูงพร้อมกันเพราะ**อุณหภูมิ/ฤดูร้อน** เป็นตัวแปรกวนที่ทำให้คนทั้งซื้อไอศกรีมเยอะขึ้น
และไปว่ายน้ำเยอะขึ้นในเวลาเดียวกัน
