## โมเดลเรียนรู้ได้อย่างไร: ลดค่า loss ทีละก้าว

การเทรนโมเดล = หาพารามิเตอร์ที่ทำให้ **loss** (ความคลาดเคลื่อน) ต่ำที่สุด **Gradient descent** ทำโดยวนซ้ำ:

1. คำนวณ loss จากข้อมูล
2. หา **gradient** = ทิศทางที่ loss เพิ่มขึ้นเร็วที่สุด (อนุพันธ์ของ loss ต่อแต่ละพารามิเตอร์)
3. ขยับพารามิเตอร์ **สวนทิศ** gradient ด้วยก้าวขนาด `learning_rate`: `w ← w − lr × grad`

ตัวอย่างเล็กที่สุด: จุดข้อมูล 5 จุดที่ y = 2x + 1 ให้โมเดล ŷ = w·x + b เริ่มที่ w = b = 0 และใช้ MSE เป็น loss

```python
import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0, 4.0])
y = 2 * x + 1

w, b = 0.0, 0.0
pred = w * x + b
loss = np.mean((pred - y) ** 2)          # 33.0
grad_w = 2 * np.mean((pred - y) * x)     # -28.0
grad_b = 2 * np.mean(pred - y)           # -10.0
w -= 0.05 * grad_w                       # 1.4
b -= 0.05 * grad_b                       # 0.5
```

## Learning rate: ก้าวเล็กเกินไป ช้า; ใหญ่เกินไป ระเบิด

วนซ้ำ 100 ก้าวด้วย learning rate ต่างกัน (ค่าจริงคือ w = 2, b = 1):

| lr | w | b | ผล |
|---|---|---|---|
| 0.01 | 2.0512 | 0.8540 | ยังไม่ถึง (ก้าวเล็ก) |
| 0.05 | 2.0045 | 0.9872 | ใกล้มาก |
| 0.1 | 2.0002 | 0.9994 | ลงตัว |
| 0.25 | ≈ −2.8×10³⁷ | ≈ −9.7×10³⁶ | **diverge** (ก้าวใหญ่จนกระโดดข้ามจุดต่ำสุดและห่างออกไปเรื่อยๆ) |

## Activation function ที่พบบ่อย

| ฟังก์ชัน | สูตร | ช่วงเอาต์พุต | ใช้ที่ |
|---|---|---|---|
| ReLU | max(0, z) | [0, ∞) | hidden layer (ค่าเริ่มต้น) |
| tanh | (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ) | (−1, 1) | hidden (แบบเก่ากว่า) |
| sigmoid | 1/(1+e⁻ᶻ) | (0, 1) | output ของ binary classification |

## ใน MLPClassifier

- `learning_rate_init` (ค่าเริ่มต้น 0.001) และ solver `adam` (ปรับก้าวอัตโนมัติ) — สำหรับข้อมูล scale แล้ว hidden (16,): lr 0.001 ใช้ครบ 200 รอบ, lr 0.01 และ 0.1 หยุดที่ ~96 และ ~95 รอบ (loss ไม่ลดพอ)
- `loss_curve_` เก็บ loss ของทุก epoch: เริ่ม 0.7329 → 0.565 ที่ 200 รอบ ลดลงโดยรวมแต่ **ไม่จำเป็นต้องลดทุกรอบ** (มี mini-batch ที่สุ่มมา)
- loss บน train ลดลงเรื่อยๆ ไม่ได้แปลว่าโมเดลดีบนข้อมูลใหม่ — ดูบทถัดไป
